# CV261102 - YOLOv8s Baseline on VisDrone2019-DET

I fine-tuned a COCO-pretrained YOLOv8s model on VisDrone2019-DET and evaluated it on the complete validation split. This experiment establishes a reproducible baseline for the UAV degradation and detector-configuration study.

## Experimental setup

| Item | Setting |
| --- | --- |
| Model | YOLOv8s |
| Training data | VisDrone2019-DET train (6,471 images) |
| Evaluation data | VisDrone2019-DET val (548 images) |
| Object categories | 10 |
| Training | 100 epochs, image size 640, batch size 4 |
| Evaluation | Image size 1280, batch size 2 |
| Random seed | 42 |
| GPU | NVIDIA GeForce RTX 4060 Laptop GPU (8 GB) |
| Framework | Ultralytics 8.4.61, PyTorch 2.6.0 + CUDA 12.4 |

## Detection results

The evaluation uses COCO metrics and object-size groups defined in original-image coordinates.

| Metric | Result |
| --- | ---: |
| AP50 | **50.42%** |
| AP50:95 | **29.62%** |
| AR50:95 | **53.17%** |

| Object size | AP50 | AP50:95 |
| --- | ---: | ---: |
| Tiny | 35.62% | 14.83% |
| Small | 51.26% | 28.39% |
| Medium | 59.21% | 38.38% |
| Large | 45.32% | 33.27% |

Medium objects achieved the highest AP50 (59.21%), while tiny objects reached 35.62% AP50. These size-specific results provide a reference for studying detector behavior under different UAV image degradations.
